## 🛠️ Tech Stack

* **Core Framework:** [React 19](https://react.dev/)
* **Build Tool:** [Vite](https://vite.dev/)
* **Icons:** [Lucide React](https://lucide.dev/) & Custom SVG Brand Icons
* **Styling:** Vanilla CSS3 (Custom Design Tokens, Glassmorphism, CSS Grid & Flexbox)
* **Form Handling:** [Web3Forms API](https://web3forms.com/)
* **Deployment & Hosting:** [Vercel](https://vercel.com/)

---

## ✨ Key Features

* **🌓 Dynamic Theme Switcher:** Seamless Dark Mode and Light Mode support with custom color tokens and smooth transitions.
* **🧩 Modular Component Architecture:** Cleanly organized into reusable components (`Hero`, `About`, `Skills`, `Projects`, `Contact`, `Footer`).
* **🚀 Featured Project Showcases:**
  * **Agentflow AI:** Automated multi-agent workflow engine built with Python, MongoDB, and Google Gemini AI.
  * **Realtime-Voice-Coding-Assistant:** Real-time voice-driven coding assistant powered by Python, MongoDB, and BigQuery.
* **📊 Categorized Technical Skills:** Interactive skill pills with category tabs (*Backend & Data*, *Frontend*, *Tools & Cloud*), bracket icons, and aligned borders.
* **📬 Functional Contact Form:** Direct asynchronous messaging integrated with Web3Forms, including client-side validation and instant feedback.
* **📱 Fully Responsive Design:** Fluid layouts optimized for mobile devices, tablets, laptops, and ultra-wide desktops.

## 🚀 Local Setup & Installation

Follow these steps to run the project locally on your machine:

### Prerequisites
* [Node.js](https://nodejs.org/) (version 18 or higher recommended)
* `npm` (bundled with Node.js)

### 1. Clone the repository
```bash
git clone https://github.com/Chandanachandu0611-cloud/react-portfolio.git
cd react-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173` to view the application.

### 4. Build for production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.
